# SILENTGRAPH — official site (v1 skeleton)

Vite + vanilla CSS/JS, same pipeline as fonica / Lapis Razli (GitHub → Netlify).

## Structure
- `index.html` — Top (dark neon dot-matrix hero) / Digital Products / Works / Goods / About
- `support/index.html` — /support (app-store support URL)
- `privacy/index.html` — /privacy (privacy policy, JP + EN)
- `src/style.css` — design tokens & layout (near-monochrome + one accent, ledger/index style)
- `src/dotmark.js` — generative dot-matrix hero (SVG, sequential light-up; static PNG fallback)
- `public/assets/` — original 2026-11-13 program-generated dot-matrix logo PNGs

## Logo system
- Primary wordmark (B): "SILENT" light + "GRAPH" bold, all caps — header, footer, everyday use.
- Dot-matrix (E): hero main visual only, glowing dots on near-black.

## Commands
```
npm install
npm run dev     # local preview
npm run build   # → dist/
```
